# 跨媒介应用

## 选择强度

- **Quiet / 阅读优先** 适合论文、长文与数据密集产品。把概念落实到图解、对位、截面和比较关系中，保留形体层级、线条轻重、统一光向和准确的文字平面。细节与动态较少，主图仍应有充分的造型与构图完成度。
- **Balanced / 标准** 适合产品介绍与交互工具。为关键任务发展一个有特点的内容结构或操作对象，其形体、光影、控件和结果构成完整关系。外围操作按使用频率保持简洁，视觉丰富度集中在值得观察的区域。
- **Expressive / 展示** 适合开场片、创意网站与展览。充分发展场景、主物件与镜头，安排清楚的空间进入和关键动作。场景设定由主题产生，高强度表现集中于叙事转折和核心操作。

三种强度都需要完整的概念、造型、光线与构图。表达强度控制场景规模、细节密度和时间节奏。用户提出高表现力要求时，应给主视觉充分的制作与打磨空间。

## 学术 PPT

先理解论文的研究问题、方法、对照、结果和局限，再选版式。使用实际提供的论文事实；缺失内容不编造。

- **封面/章节：** 从研究对象找到有辨识度的主图或结构，将其轮廓、尺度与明暗设计到位，标题与图像形成清楚的关系。纸白与深色空间按内容决定。
- **研究问题：** 编辑式大命题 + 一项关键证据，不用游戏人物或武器代替内容。
- **方法：** 找到算法的实际作用点，用路径、分层、对齐、截面或对象变换呈现机制。形体厚度、遮挡和光影帮助读懂结构，公式与符号保持准确。抽象算法可以使用原生图示。
- **实验：** 同尺度图表、对照组与图例。只有提供了相应不确定性数据时才绘制误差线；不补造样本量、方差或显著性。把纸纹放到外部背景，绘图区、数据标签、公式保持干净。
- **消融/比较：** 使用并置印样的逻辑；各方案共享尺度、位置和可比信息。
- **结论/局限：** 正常陈述证据强度；「已验证」章只有在真实验证语境下才能使用。可用编号、圈注或纸签强调结论。
- 不强制页数、每页三卡、机械道具或某种论文叙事。内容决定结构。
- 优先让文本、图表和箭头可编辑。用所需演示文稿工作流导出并逐页检查。
- 动画仅在交付格式支持且有必要时使用；静态版本保留完整信息。若无法保留某种动画，选清楚的静态构图，而不是用截屏替代整份可编辑 PPT。

## 静态网页 / 长文 / 海报

- 长文使用纸面编辑秩序，章节编号、页边注、图注与清楚链接。
- 海报强调一幅图、一个主标题与少量标记。需要工业感时可加登记号或校准线；这些要有内容意义。
- 原作的三维空间可转译成窗口、遮挡、裁切和长影，无需真的建立 3D 场景。
- 响应式重排图文关系，不把桌面舞台等比缩小到手机。清晰度优先于保留所有装饰。

## 动态网页 / 应用 UI

- 使用标准 HTML 控件/原生组件的可访问行为，在视觉层应用纸墨和器物语言。
- 数据密集页面保留适合任务的表格与列表。通过列组的空间关系、关键比较图、局部剖面、严谨的线条层级与选中对象的连续性建立个性。
- 主导航稳定。选中项和详情之间建立明确关联。集合页、详情页和编辑器选不同布局语法。
- 大场景转换主要用于首次进入、章节切换或显著层级变化。搜索、筛选、保存等高频动作保持快速。
- 纸卡倾斜、印章和网点不要改变点击区域与阅读顺序。
- 按真实操作提供 hover、focus、selected、disabled、loading、error 等适用状态，勿只实现静态外观。同步本地操作无需制造加载或错误状态。
- 不因这个 skill 自动选择某个前端框架、托管服务、公开发布方式或第三方依赖。

## 演示视频 / Motion Graphics

先确定每个镜头中观众理解的关系，以及下一镜头怎样继续这条关系。材料、方法和结果应保持可追踪的身份。对象可以是实体、数据、图形或文字，镜头构思服从内容。

- 设计稳定关键帧，再设计关键帧之间的信息关系。
- 可把圆形/两面/翻转作为贯穿线索，但不要直接复刻原作 logo 或 FLIP SIDE 品牌字样。
- 章节用强转场，内容用弱转场。让观众有时间阅读完整静止状态。
- 字体、数字和标记的运动应有层级；不能所有元素同时抢注意力。
- 对录屏内容保真；可以加外部标签与取景窗，不篡改实际操作与结果。

## 插画 / 静态 UI / 特效素材

- 插画强调轮廓、色面、冷蓝长影与纸墨细节；依据对象调整线条密度。
- UI 静态稿至少覆盖重要状态或说明交互意图；不要把漂亮空壳称为已实现应用。
- 单独动效素材要指定透明/不透明背景、尺寸、循环与结束态需求，按用户已有信息执行。
- 输出新图像时使用当前环境合适的图像制作工具；不把源视频截图直接用作新项目美术。

## 三个调用例子

> 使用 $flipside-design 作为审美标准，帮我做一份学术论文汇报 PPT。保持图表准确、文字可编辑，风格强度偏 Quiet。

> 使用 $flipside-design 设计这个产品的响应式页面，采用 Balanced 强度，保留当前品牌标志和现有功能。

> 使用 $flipside-design 做一段方法介绍动画，以“输入变成结果”为主要动作，整体 Expressive，但正文出现后保持稳定。

这些例子展示调用方式，不是固定的任务限制。用户可以指定其他风格强度或不同媒介。
