## 已澄清的模糊点

| 问题 | 目前最有依据的判断 | 仍未知的部分 |
|---|---|---|
| 「是什么风格」 | 漫画式空间 + 纸墨编辑设计 + 工坊/机械实物隐喻；「翻面·印刷工坊美学」是本 skill 的归纳名称 | 作者是否使用了既有正式风格名称 |
| 字体 | 至少可区分重黑体、宋/明朝体、窄体数字/英文与常规小字等角色 | 字体家族、字重文件、是否做了自定义修改 |
| 配色 | 反复出现纸白、近黑、冷蓝、锈橙，辅以粉黄及黄铜色 | 原始材质色、光照/后期前的色值 |
| 色觉选项 | 页面明确标注红绿色弱、蓝黄色弱、全色盲、单色等模拟 | 具体模拟算法；不能当作普通主题皮肤 |
| 网点与描边 | 设置页直接提供网点密度与描边粗细的视觉样本；实机场景呈现相应非写实观感 | 渲染管线、shader、贴图或后处理的分工 |
| 动效 | 已确认滚轴、铰链/翻面、源到目标转印、镜头推近、分批进入、圆形揭示及斜边擦除 | 作者设置的精确 duration、easing、物理参数 |
| 纸纹/磨损 | 纸面颗粒、墨迹、木金属磨损可见；材料有差异 | 是否扫描实物、程序纹理或手工绘制 |
| 全部 diegetic? | 物件化界面与常规屏幕 HUD/按钮混合 | 游戏世界如何在叙事上解释每一个控件 |
| 主页黑色导航条 | 反白条会随指针移到不同入口，表示当前指向/聚焦的项目 | 没有实际运行游戏，不能仅凭样式推断完整 hover/focus/active 实现 |
| 暗色背景 | 多次出现有结构的冷蓝木墙、暗房和工作台；不是单一纯黑底 | 美术资产的真实构造 |
| 定格/抖动 | 没有充分证据把低帧定格或持续抖动当作系统特征 | 个别运动是否使用特定帧率技巧 |

## 新发现的设计亮点

1. **视觉与语义互相解释：** 光学窗口对应画面比较，声场对应音量，字模对应按键，压印对应准星，沙盘对应地图选择。
2. **物件变化，操作骨架稳定：** 页面高度多样，但标题/分类/状态/快捷键/主动作反复落在相似区域。
3. **「翻面」贯穿形状、动作与叙事：** 半黑半白圆、双阵营、卡片正反面、字标共同组织转换。跨媒介可借用两面/对照关系，而无需搬用游戏标志。
4. **状态直接印在物件上：** 已购、已入册、已用、未开刃和价格签让对象具有经历，而不仅是一张孤立缩略图。
5. **商品卡本身演示商品：** 样式/枪焰预览嵌在印样里，降低选择与结果之间的距离。
6. **动作有来源和去向：** 手画图案离开纸、贴到目标；相机进入选中标牌；柜门打开后出现内部陈列。
7. **冷影承载空间：** 远景不依赖写实材质堆叠，蓝色影子与暖受光面就能建立深度。
8. **局部密度反差：** 工坊器械很细，纸卡与天空很疏；视觉复杂度集中在当前对象。

## 使用这些图像

这些截帧与联系表用于私人设计分析、核对和学习。后续项目应生成与其内容相符的原创图像和布局；不要把作者水印、游戏 logo、角色或原画当成这份 skill 提供的通用可复用美术资产。
