# 页面与组件：让物件服务内容

先依据 [design-reasoning.md](design-reasoning.md) 确定主题与关键关系，再选适合的组织方式。下面的源布局是可分析的实例。新的任务可以产生新的布局与主形体。组件的曲率、厚度、线条和阴影按 [form-light-space.md](form-light-space.md) 共同设计。

## 稳定的骨架

原作在多种场景里反复保持：左上标题与细锈橙线、其下紧凑的分类、右上状态、底部快捷键、右下主动作。中心内容可以从纸样换成暗房、沙盘、机械台，操作位置仍容易找到。

迁移规则：保持身份、当前位置、内容主区、详情、主行动之间的关系。移动端可把主动作放在内容末尾或可访问的底栏；PPT 用标题/页码/核心结论对应这些角色。

## 六种布局语法

根据内容选择，不要求每份作品都使用全部布局。

| 语法 | 原作例子 | 可迁移内容 | 关键关系 |
|---|---|---|---|
| 门框/取景窗 | 00:19 主菜单 | 封面、产品入口、核心论点 | 中央主体与通向远处的视线；两侧信息支持主体 |
| 校样/标尺 | 00:28 色彩页 | 参数、方法、前后对比、设计规格 | 左侧控制/论据，右侧对应预览；标签与刻度直接关联 |
| 陈列柜 + 档案 | 01:09 挂坠、01:30 印花 | 案例库、模型/方案选择、资料库 | 左侧扫描集合，右侧聚焦详情；选中项与详情保持同一身份 |
| 印样并置 | 01:21 UI 样式 | 消融实验、设计版本、实验组对照 | 同尺寸/同尺度比较，差异有明确标记 |
| 工作台 | 02:09 军械库 | 编辑器、方法流水线、素材到结果 | 输入在一侧，主对象在中央，工具在另一侧；操作有去向 |
| 沙盘/地图 | 02:50、08:40 | 研究路线、系统结构、空间导览 | 俯视全局与可进入的局部；每个标牌对应真实内容 |

### 避免布局机械化

- 大标题 + 三张卡片只是一个选择，不是默认模板。
- 长文使用清楚的单栏/双栏编辑结构；数据页让图表占据主区；复杂界面保留标准表格、表单、树或列表。
- 装饰性倾斜只给少量物件，通常不超过约 1–3°。标题、坐标轴、表格与连续正文保持直正。
- 先分配留白、图文比例和阅读顺序，再放夹子、编号、标尺。标记应有身份或定位用途。

## 组件语言

### 导航

深浅反转的矩形定位块、小三角指示、短标题与次级说明。源视频主页黑条会随指针移到不同入口，不能一概当成已进入页面的状态。迁移时分别处理悬停、键盘焦点、当前页面与已选项目；可加半圆/短线等第二信号，不只靠墨色变化。

### 纸卡与档案

先判断内容是否适合独立纸片或档案。需要扫描时保持稳定对齐，标题、图像与状态按实际阅读顺序安排。薄纸使用轻薄边缘与接触投影，厚板可以显露侧面，局部弯折或切口应交代材料与结构。编号用于真实身份或导航。选中项通过位置、边界、亮度和可读状态建立关联。

### 主按钮

主按钮需要明确文字、足够对比与可辨认的操作区域。其形状服从承载面与动作，嵌入面板的按键、曲面上的把手和纸面的行动区可以各有造型。锈橙配浅字是源作的一种处理，具体颜色与几何由当前设计决定。快捷键提示保持次级，真实的忙碌与完成状态应可识别。

动作名要贴合内容。原作使用「入册」「显影」「印」「开刃」一类工艺动词，增强材料一致性。迁移到学术或业务任务时保留真实动作含义：例如「查看证据」「导出」「运行分析」，不要为了文艺而降低可理解性。

### 印章与票签

适合表达已购买、已验证、完成、版本、审批等真正存在的状态。可轻微倾斜或有细缺墨；字样必须可读。不要给所有结论盖「已验证」章，尤其不能以装饰暗示不存在的验证。

### 刻度、控件与标尺

调节项可使用刻度条、样条、纸面红圈、机械旋钮或细线，但仍要显示当前值和单位。圈选/三角/反白与文字配合。连续值用连续控件，离散选项用离散样本；不要为拟物造型改变控件含义。

### 预览

原作商品卡内部会播放对应效果，所选样本更明亮，其他卡降低注意力。迁移时保持比较条件一致，让用户看到选择的结果。动图仅在有益时播放；列表中避免所有预览同时高强度运动。

### 标签、图注与页脚

小型标签使用短词、编号、单位、键帽或明确的图例。技术标记要能解释；减少装饰性的乱码、假编号、无用角标。PPT 不照搬底部一排快捷键。

## 状态矩阵

| 状态 | 建议信号 | 需要保持 |
|---|---|---|
| 默认 | 稳定边界、正常对比度 | 可读标题与行动能力 |
| hover/focus | 细边/偏移/三角，清楚的焦点 | 不触发布局跳动；键盘可见 |
| selected | 反白或浅纸高亮 + 标记 + 同步详情 | 单一、明确的当前位置 |
| pressed | 轻微压低/暗一档 | 字不缩到难读 |
| completed/owned | 印记或状态签 + 可读文字 | 不冒充选中或禁用 |
| disabled | 降低对比 + 原因 | 必要信息仍可读 |
| loading | 简洁环/进度标签，保持所选对象 | 不通过装饰动画伪造进度 |
| error | 明确错误文本与修复动作 | 锈橙主操作色不自动承担所有错误语义 |

## 信息亮点的迁移

- **功能隐喻不同、材料世界相同：** 参数可用校样，选项可用档案，路线可用地图；无需所有页面放同一种纸卡。
- **切换前后保留同一对象：** 卡片被展开，缩略图成为大图，地图节点成为详情标题，图像转印到结果对象。
- **视觉锚点减少迷路：** 场景变化大时，标题、动作区和选中项身份保持稳定。
- **量化信息优先准确：** 原作零击杀时罐内也有大量硬币，所以装饰堆积不能直接成为图表范例。数据使用正确的刻度、长度、面积或直接数值。
