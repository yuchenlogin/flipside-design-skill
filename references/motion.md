# 动效从内容变化与结构产生

先描述用户做了什么，以及哪个对象发生了什么变化。再从对象的结构、材料和空间关系推导动作。下方源片段可以帮助分析连续性，具体时长在当前使用情境中确定。

## 构思一次有因果关系的动作

为关键行为画几个足以读懂变化的状态。记录输入对象的身份、可运动的部分、固定的部分、作用位置、输出的身份和最终落点。完成后的画面需要清楚解释操作结果。

| 需要解决的问题 | 设计时的依据 |
|---|---|
| 用户从哪里发起 | 控件与受影响内容邻近或有明确对应，发起瞬间有可识别反馈 |
| 哪部分允许移动 | 轴、铰链、轨道、支点、柔性边或信息布局给出约束 |
| 动作怎样发展 | 材料、重量和动作目的决定加速、阻力、弯折及停顿 |
| 作用在哪里发生 | 接触、对齐、合并、穿过或显现应落在实际关系发生的位置 |
| 结果如何确认 | 内容、状态和可继续操作的对象保持可读，变化留在有意义的位置 |
| 重复使用会怎样 | 高频行为直接接续当前状态，允许中断和连续调整 |

物件移动时，透视、遮挡和影子要共同变化。抬离台面的薄片，其接触阴影与投影应反映高度变化。绕轴翻开的对象应让人看到约束，薄片弯折与厚板旋转有不同的观感。采用简化表达时，保留最能解释作用的几何关系。

运动曲线首先表达目的。快速选择需要及时反馈，承重结构落定需要有分量，柔性材料可以在末端继续一点动作。对象的重量和柔韧性并非同一个参数。轻微过冲仅在该结构和动作允许时使用。

## 由操作推导动作的例子

- 调整一个裁切范围时，固定原图与定位点，边界沿允许的方向变化，预览持续对应真实结果。
- 组合内容时，让被加入的单位保持身份，在结果结构中找到落点。用户能沿变化追踪来源。
- 解释剖面时，让切面与内部内容保持共同坐标。镜头或遮罩的推进揭示原先被遮挡的结构。
- 比较两个状态时，保留尺度和锚点。局部替换、叠合或分界移动可以让差异直接显现。

静态输出以对位、连续路径、局部剖面或明确的前后状态承接同样的信息。减少动态效果时仍保留对象身份、作用关系和最终结果。

## 动作选择表

| 用户/叙事意图 | 适用动作 | 减弱或不用的场景 |
|---|---|---|
| 揭示一个完整新页面 | 卷轴展开、遮罩开窗 | 高频表单操作；长文阅读 |
| 同一对象的另一面/另一状态 | 纵轴翻面、翻页 | 无对应关系的随机跳页 |
| 从全局进入局部 | 从选中对象推近、局部展开 | 只有标题变化的页面 |
| 输入变成结果 | 源到目标的转印、位置连续的变形 | 单纯的按钮 hover |
| 确认一次完成 | 印记落定、短促墨点/压印 | 每次移动鼠标；未经验证的结论 |
| 选择或比较 | 抬起、增亮、细边与标记 | 所有卡片一起浮动 |
| 章节/品牌强调 | 卡片收拢→翻面→揭示下一幕 | 每一个小操作 |
| 顺序解释 | 沿阅读顺序分批进入、线条逐步延伸 | 数值间不应暗示因果的图表 |

## 迁移参数：建议起点，非原作参数

| 层级 | 建议时长 | 建议幅度 |
|---|---|---|
| hover / press | 100–160 ms | 1–3 px 压低或 2–4 px 抬起，颜色/边界变化 |
| 局部选择与卡片切换 | 180–280 ms | 4–12 px，轻微尺度变化，避免布局重排 |
| 纸面/面板出现 | 320–480 ms | 约 16–32 px 或从物件边界展开 |
| 同一对象翻面 | 450–700 ms | 围绕真实/可理解的轴，遮住背面文字 |
| 场景推进与章节揭示 | 700–1100 ms | 明确焦点，保留视觉锚点 |
| 分批进入间隔 | 50–90 ms | 按语义分组，不逐字轰炸 |
| 完成印记 | 180–300 ms | 轻微过冲后稳定，可叠加极短反馈 |

常规进入可从 `cubic-bezier(.18,.8,.28,1)` 起步；进出/镜头用平滑缓入缓出；只给实体压印一次轻微过冲。不要把每个动作做成弹簧。

## 场景组合

一次较大的切换通常拆成：**收束旧内容 → 材料/空间转换 → 新主对象落位 → 次级信息补入**。根据任务删除不必要的阶段。频繁操作应直接反馈，不必重复品牌段落。

- 对比/翻面前后保留一个锚点，例如标题、对象中心、编号、轴或图例。
- 屏幕固定导航与运动场景分层处理。避免整屏同步漂移造成定位困难。
- 前后层可以有适量视差；只有在确有深度关系时使用。
- 文字在旋转边缘、半透明中间态不要成为必须阅读的信息；最终状态要稳定且清楚。
- 加载可以使用半圆/环形语言，但真实进度由实际状态决定。

## 特效与声音

线弧、短星芒、少量纸屑、墨点可承接划动、命中或完成。把它们限制在行动发生的位置，短暂结束。论文演示通常选划线、路径与纸面揭示即可。

这次分析没有做原视频音轨的逐事件测量。若另行制作声音，可建议纸张、机械轻响、短压印音作为新方案，但不能称为复原原作音效；用户未要求时不自动加音。

## 可访问性与验证

- 尊重 reduced-motion：把大转动、视差、推近替换为短淡入或即时状态切换，保留同样的信息和操作。
- 静态截图/导出必须落在完整结束态，不残留模糊、半翻转或透明文字。
- 控件动画不锁住键盘焦点，不让按钮逃离指针，不制造长队列；重复操作应中断/接续当前状态。
- 验证动作的起点、经过和落点；只看静止截图不能证明动画成立。
