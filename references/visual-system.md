# 视觉系统：纸墨、光影、字体与材料

这里的规则是从原视频提炼的跨媒介规范。标为「观察」的内容来自画面；数值与替代字体均为复用建议。时间证据见 [evidence.md](evidence.md)。

先完成 [design-reasoning.md](design-reasoning.md) 的概念判断，并依据 [form-light-space.md](form-light-space.md) 建立形体、线条与光照。下列颜色和材料用于细化已经成立的构图。

## 整体美术

**观察：** 场景、人物和武器保留三维透视与遮挡；黑色外轮廓、细节线、简化材质、成块明暗与长投影使它们呈现漫画感。木桌、皮革、金属的细节密度高于远景。纸面、卡片和字样又保留较明确的平面编辑秩序。

**归纳：** 漫画式非写实画面 + 印刷工坊/档案/机械器物语言 + 平面编辑设计。`Graphic novel`、`print-inspired`、`tactile editorial` 比单个「复古」标签更能限定结果。Riso、丝网印刷、版画是相邻参考；不能由视频确定实际模拟工艺。

### 图像处理

- 轮廓有主次：外轮廓清楚，内结构线细，远景降低复杂度。避免给所有物体同样粗的边。
- 明暗以面组织；需要渐变时，可在插画局部用点、排线、细颗粒承担过渡。不要给正文铺满网点。
- 暖纸色/石色受光面与冷蓝色阴影相对。长投影既交代光线，也把视线引向主体。
- 物体可以真实地投影、旋转、遮挡。不要把全部输出压成平面海报；也不要给平面信息添加无意义的厚重三维装饰。
- 截图、显微图、医学图像、论文原图等证据图保真。允许外部加纸框、编号和说明，不以风格滤镜改变证据本身。

## 配色：先分角色，再决定比例

| 角色 | 建议值 | 用途 |
|---|---|---|
| paper | `#ECE5D6` | 主阅读面、纸卡、浅色章节 |
| paper-muted | `#DCD5C5` | 次级纸层、未激活纸卡、分区 |
| ink | `#20211F` | 正文、轮廓、反白选中块 |
| night | `#101923` | 深色展陈底、黑场、舞台外部 |
| navy | `#182C45` | 工坊空间、深色章节、外壳 |
| blueprint | `#30466C` | 次级蓝面、冷影、图示结构 |
| rust | `#A64F32` | 主动作、确认印记、当前项目 |
| pink | `#D5A3AD` | 安静的次级色块、场景分区 |
| yellow | `#D9C45B` | 少量高注意标签、关键数值 |
| brass | `#B59A5B` | 可选机械细节、描边、实体控件 |

这些颜色不是原作底层色值。源视频取样范围存在明显光照差：纸面中位色约 `#E0DBCF`—`#EDE5D7`，蓝色场景从近黑蓝到 `#23335D`，按钮取样为较暗的 `#91432C`。完整取样矩形见 [palette-samples.json](palette-samples.json)。色觉模拟页里的粉黄蓝样块仅用于辅助辨认色相，不作为主题选择证据。

### 组合方式

- **纸本阅读：** 大面积纸白，墨黑信息，锈橙只强调一个主动作或重点；蓝色交代图像与章节关系。
- **深色展陈：** 深蓝/近黑空间，纸卡作为主要信息面，暖木色或锈橙提示物件和操作。纸白卡片并不要求占满屏幕。
- **冷暖场景：** 暖建筑与纸白地面，硬边蓝影；灰粉可做大片低注意区域。
- 同一页面通常只启用一至两个强调角色。保留其他颜色用于后续章节或真实类别，不把全部色样均匀撒满屏幕。
- 颜色同时配合形状、文字或位置。使用纸白文字的锈橙按钮须检查实际对比度；粉、黄底上优先用墨黑字。
- 不强制固定 60/30/10 面积比例；由阅读面、空间和主行动的层级决定。

## 字体：确认角色，不伪造字体鉴定

原视频无法可靠识别字体文件。可见的是以下角色组合：

| 角色 | 源画面特征 | 推荐替代，不是原字体鉴定 |
|---|---|---|
| 导航与大标题 | 黑体、粗重、紧凑，短词直接 | 思源黑体 Heavy / Noto Sans SC 800–900；已有品牌黑体也可 |
| 商品、物件与编辑标题 | 宋/明朝体气质，笔画粗细对比，字面较舒展 | 思源宋体 SemiBold / Noto Serif SC 500–700 |
| 大数字与短英文 | 窄长、醒目、垂直节奏强，如价格、柜号、FLIP SIDE | Barlow Condensed 或 Roboto Condensed 600–800；本机已许可的 DIN Condensed 可用 |
| 正文与说明 | 小而规整，依靠块面、行距和对比度区分 | 常规黑体 400–500，按目标阅读距离放大 |
| 编号与技术标签 | 小写量、短字串、字距与细分隔线 | 窄体/常规 sans；仅需对齐代码或数字时才选等宽体 |

- 默认两种主字体足够：黑体承担信息、宋体承担编辑气质；数字很多时再加一个窄体。不要每个组件换一套字体。
- 宋体点缀可局限于章节题名、案例名或物件名；导航、表格、长段落保持稳定。
- 大标题可以紧凑，小号标签和英文可略放宽字距；正文不人为压扁或拉伸。
- 使用可编辑文字。确需把品牌标题做成图形时，正文与数据仍保留为文字。
- 不把水印、视频字幕、浏览器提示当作游戏字体。

### 面向媒介的建议尺度

- **16:9 PPT：** 主题标题 34–46 pt，章节数字 70–120 pt，正文 22–28 pt，图注尽量 14–18 pt。按内容密度调整，避免照搬游戏里极小的标签。
- **桌面网页：** 正文 16–18 px，标签 12–14 px，标题约 32–56 px；移动端重新排版。
- **视频：** 根据成片分辨率与观看设备检查字高。用真实尺寸预览，不把源视频的小字作为可读性标准。

## 材料：不同表面分别处理

### 纸

暖色基底、细颗粒、轻微色差，少量裁切角、折角、票据边、装订孔或夹子。大多数阅读边界仍然整齐。建议纹理不透明度约 2–5%，在投影或小屏时进一步减弱。

### 油墨

局部缺墨、细颗粒、排线、半调点与手画圈。原作的红圈不完全规则；正文和关键数值仍应清晰。多色套印错位可作可选延伸，不能宣称原作普遍存在明显错版。

### 木与机械

蓝色木板、暖木框、层级明确的抽屉分格、磨损边缘与铆钉；压印机的黑色金属和黄铜把手可带局部高光。只在有功能含义的工作台/器械界面使用，勿把每个产品做成蒸汽朋克。

### 阴影与立体

纸的抬起使用短、明确的阴影；场景可以使用方向性很强的长影。前景信息平面与环境分离。全屏模糊毛玻璃、浮空软阴影和持续发光会改变这套审美的重心。

## 特效语言

原视频可见线性的刀光弧、星芒/碎片状枪口反馈、纸片/墨点感粒子，以及清楚的物体动作。归纳为「图形化、高辨识、短暂」。

迁移时选择与动作有关的图形：完成是印记/短墨点，路径是线段逐步延伸，切换是翻面/遮罩，揭示是滚轴/开窗。特效应结束并让内容稳定，不用大面积尘粒持续干扰阅读。
