# Open Kiln · 开窑日的门与名册

活动小站。读者先辨认窑门与地点，再打开对应时段的说明。

**母题选择**（贴合 / 辨识 / 可动画 / 可读，各 0–5）。窑门截面 5/5/5/5　·　釉色试片 4/5/4/3　·　拉坯转盘 4/5/4/3　·　泥条盘筑 4/5/4/4　·　窑柱 4/3/2/3　·　围裙口袋 3/4/3/3　·　火苗 3/4/3/2　·　窑砖标记 4/4/3/3　·　瓷片拼图 4/4/4/2　·　门票撕口 3/4/3/4。采用首项。釉色试片适合比较成品，无法替整个开放日定场；火苗会误导观众以为开窑时仍在燃烧。

**材质、签名与镜头**　◠ 取窑门拱线。左半切开夯土拱门，砖层贴在深色窑壳上；右侧细纹登记纸列出时段。 镜头固定，各层指针视差为零。保持文字、刻度和点击位置稳定。

**墨与字**　按纸 / 墨 / 深场 / 热主调 / 淡色 / 信号列出 RGB：ffebcf / 3b2b29 / 642c29 / 9a392b / f2dfc4 / d38358；烧成红的大面积使用为开场色彩事件。 本地 Noto Sans SC 承载说明，Barlow Condensed 承载编号与窄幅读数；叙事标题需要衬线时用 Noto Serif SC。缺字符号由本地 Noto Sans SC 补齐。

**运动与输入**　fire 550ms，拱门由下入场，无过冲；unfold 240ms，打开时段时说明就位。收起其余时段，保持单一阅读焦点。 缓动见同目录样式的同名 keyframes 与 animation 声明；减少动态时直达终态。无音轨。

**边界**　左上标地点来源，左下放门牌与活动日，右侧时段都可触控或聚焦展开。门体压住门壳，底端出血。 单屏以小字边距定位，正文标题留给舞台。最大物件宽度至少为页边最小字高度的六倍。
