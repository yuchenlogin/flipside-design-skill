与 poster/index.html 严格同题同字。退潮后绳索松弛，以绳长、重力和受力曲线重写横向潮沟。

**母题选择**（贴合 / 辨识 / 可动画 / 可读，各 0–5）。缆绳垂弧 5/5/5/5　·　等深线 5/5/5/5　·　声谱条带 4/4/3/3　·　风旗 4/4/4/2　·　防波石 4/3/3/3　·　涨落闸门 4/4/4/3　·　渔网菱格 3/4/3/2　·　链条 4/4/4/3　·　铃舌 3/5/4/3　·　脚印 4/3/3/3。采用首项。等深线已经是对照稿的机制；铃舌指向单点声源，弱化整段海岸步行。

**材质、签名与镜头**　◎ 指向系泊环。三束粗绳垂在粗横纹织物上，端部裁出顶框，向右下投硬影。 镜头固定，各层指针视差为零。保持文字、刻度和点击位置稳定。

**墨与字**　按纸 / 墨 / 深场 / 热主调 / 淡色 / 信号列出 RGB：e9d1b8 / 37212a / 301d2a / a84d34 / e7c8a3 / b77e69；暖织物左场为一次色彩事件。 本地 Noto Sans SC 承载说明，Barlow Condensed 承载编号与窄幅读数；叙事标题需要衬线时用 Noto Serif SC。缺字符号由本地 Noto Sans SC 补齐。

**运动与输入**　sway 580ms，悬挂点固定，三条绳先后相差 75/65ms，第一次回摆 2°；pull 310ms，标题拉入。最终静止。 缓动见同目录样式的同名 keyframes 与 animation 声明；减少动态时直达终态。无音轨。

**边界**　活动类别和地点在右上，右下保留日期及集合处。绳索盖住织纹，左边场越界。 单屏以小字边距定位，正文标题留给舞台。最大物件宽度至少为页边最小字高度的六倍。
