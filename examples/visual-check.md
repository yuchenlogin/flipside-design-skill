# 七个单页的两轮校样

2026-11-18。以下是制作者的逐页自评。第一轮和第二轮均在 Chrome 查看 1280×720 桌面、390×844 手机的全页与联系表。第二轮另查 960×600 的遮字稿及 0、150、300、600ms 序列。本地字体为 Noto Sans SC、Noto Serif SC、Barlow Condensed。七张独立小样各按自己的 world.md 判断，只有两张 Low Tide 共享原题。

分数顺序为主角 / 差异 / 尺度 / 遮挡与破框 / 材质 / 动效 / 复制项数 / 可读性；复制项数以零为通过，其余以五分为满分。差异分用整组横向比对；同题材质差异只在两张海报上可直接判断。窗口尺寸与这些分数有关，勿视为设备性能或作者偏好的测量。

| 页面 | 第一轮 | 画面问题或核查点 | 第二轮 | 修订后的实际证据 |
|---|---|---|---|---|
| 学术汇报 | 4/4/4/3/4/4/0/3 | 手机版 Field Notes 来源标记换为两行，与右侧系列名争空间 | 4/4/4/3/4/4/0/4 | 来源保持一行；缩略图可分出两个高度，遮字后只剩柱对。正文给出 11°C、同址、正午与示意数据。 |

首轮优先修三处：产品轮廓的误读、系泊海报的信息遮挡，以及多个窄体标题的字距。第二轮另修了本地字形与运动采样：看板波纹改用本地字形，活动站拱门以 CSS 画出；试听前不创建连续旋转动画。两个海报使用相同标题、类别、日期、集合时间与地址；遮字后仍可凭水纹退移与悬绳回摆辨认世界。

在桌面和手机视口，逐页检查未出现横向溢出或 JS 异常。打开“减少动态”后无持续或入场动画运行，交互后的数字和文本反馈保留。持续帧率、真实手机触控和设备音频质量不在本次自评范围。

## 同题对照后的校样

逐题根据盲评改了轴与同址表述、试听节拍与音符、旋钮角差、海报集合信息、七日读数和场次切换。切换输入重新实测，包括四次右箭头后锁定、试听启停、从上午转到下午、在看板选 12 日。新一轮复看画面与评者意见见[同题对照](../evals/blind-comparison.md)。
