# Phase Lock · 对相仪

游戏 UI。玩家以 15° 为一步将绿色指针与琥珀靶标重合，锁定后进入下一关。读数允许精确操作。

**母题选择**（贴合 / 辨识 / 可动画 / 可读，各 0–5）。对相仪 5/5/5/5　·　双层光阑 5/4/4/3　·　漂移示波线 4/5/5/2　·　插销 4/4/3/3　·　双锁孔 4/4/3/4　·　摆锤 3/5/4/2　·　方向盘 3/4/3/4　·　弹簧卷尺 3/3/4/3　·　变速齿轮 4/4/4/2　·　极坐标棋盘 4/3/2/3。采用首项。示波线要解释波形和时间尺度；摆锤会暗示必须赶时间。

**材质、签名与镜头**　向内三角兼作刻度目标。深色面板钻出圆形刻度槽，指针叠于同心环上；左上光，底缘短硬影。 镜头固定，各层指针视差为零。保持文字、刻度和点击位置稳定。

**墨与字**　按纸 / 墨 / 深场 / 热主调 / 淡色 / 信号列出 RGB：e2ead1 / 1e292a / 18202a / f1b587 / bad5b4 / d2ed85；热色仅占靶标，浅绿用于确认。 本地 Noto Sans SC 承载说明，Barlow Condensed 承载编号与窄幅读数；叙事标题需要衬线时用 Noto Serif SC。缺字符号由本地 Noto Sans SC 补齐。

**运动与输入**　tune 450ms，仪表转稳；click-in 300ms，成功文字确认。无过冲。静止仪表保持稳定；箭头、按钮和键盘聚焦的按钮操作相同。 缓动见同目录样式的同名 keyframes 与 animation 声明；减少动态时直达终态。无音轨。

**边界**　仪表上方给关卡，底部是能实际旋转和锁定的按键。转轴叠在针根。 单屏以小字边距定位，正文标题留给舞台。最大物件宽度至少为页边最小字高度的六倍。

**同题复核后的取舍**　旋钮内环的有色弧显示有符号角差；锁定成功后闭合成整圈。
