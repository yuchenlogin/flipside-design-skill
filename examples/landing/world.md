# Spool · 可回转的卷盘

产品落地页。访客试听四拍循环并可立即停止；体验目标是听见同一句回到起点。

**母题选择**（贴合 / 辨识 / 可动画 / 可读，各 0–5）。录音卷盘 5/5/5/5　·　沟槽唱盘 4/5/4/4　·　循环履带 3/5/3/3　·　回形针 2/4/3/4　·　钟摆 3/5/4/3　·　折页乐谱 4/3/3/3　·　滚筒 3/4/4/3　·　磁带盒 5/4/3/4　·　弹片列 4/4/4/3　·　采样窗 3/3/3/5。采用首项。唱盘容易读成播放已有唱片；折页乐谱可以展开却不能表达连续回卷。

**材质、签名与镜头**　◉ 是轴心。带材同心线包紧开孔金属盘芯；盘缘越过右侧边界，硬影向右下。 镜头固定，各层指针视差为零。保持文字、刻度和点击位置稳定。

**墨与字**　按纸 / 墨 / 深场 / 热主调 / 淡色 / 信号列出 RGB：fff6ca / 231d20 / 382735 / f0cc54 / facd60 / e7b250；整幕蜡黄色为演示启动页的色彩事件。 本地 Noto Sans SC 承载说明，Barlow Condensed 承载编号与窄幅读数；叙事标题需要衬线时用 Noto Serif SC。缺字符号由本地 Noto Sans SC 补齐。

**运动与输入**　thread 580ms，卷盘从右侧就位；wind 每 6s 匀速一圈，只在播放时运行。无过冲。按钮触发 Web Audio，96 BPM，每拍 625ms；离开标签即停。 缓动见同目录样式的同名 keyframes 与 animation 声明；减少动态时直达终态。

**边界**　产品标记与分类列于顶端，底部给四拍与速度。近层卷盘在右侧被裁切，文案和按钮留在安全区。 单屏以小字边距定位，正文标题留给舞台。最大物件宽度至少为页边最小字高度的六倍。
