# Field Notes · 成对的温度样本

学术汇报，投影距离。读者先识别两根柱子的高度差，再核对同址、正午、零基线和两个摄氏读数。虚构数据。

**母题选择**（贴合 / 辨识 / 可动画 / 可读，各 0–5）。温标对照 5/5/5/5　·　热像色斑 5/5/4/2　·　剖面地层 4/3/4/3　·　热流箭头 3/4/3/3　·　测站地图 3/3/2/3　·　日轨 4/3/3/2　·　屋顶模型 3/3/3/2　·　翻页记录 3/3/4/4　·　道路剪影 5/4/2/2　·　钟盘 3/4/2/3。采用首项。热像色斑会把两个离散点暗示成连续观测；日轨会暗示存在全天记录。

**材质、签名与镜头**　◒ 标示日照与阴影。暗绿记录板上叠放硬边图框，水平刻线落在柱后；左上光、右下硬影。 镜头固定，各层指针视差为零。保持文字、刻度和点击位置稳定。

**墨与字**　按纸 / 墨 / 深场 / 热主调 / 淡色 / 信号列出 RGB：f9edcd / 243b35 / 263c37 / efb285 / cbd5b5 / d4dfaa；杏色限日照柱。 本地 Noto Sans SC 承载说明，Barlow Condensed 承载编号与窄幅读数；叙事标题需要衬线时用 Noto Serif SC。缺字符号由本地 Noto Sans SC 补齐。

**运动与输入**　rise 500ms，底边固定，先日照再阴影，相差 100ms；tag 320ms，0.3s 起归位。两者无过冲。 缓动见同目录样式的同名 keyframes 与 animation 声明；减少动态时直达终态。无音轨。

**边界**　页眉识别研究系列，页脚写明样本数与页码。图框压在影子上，投影页保留完整刻度。 单屏以小字边距定位，正文标题留给舞台。最大物件宽度至少为页边最小字高度的六倍。
