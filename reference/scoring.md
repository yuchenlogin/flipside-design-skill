# 看图验收

按目标尺寸渲染全部页，先看联系表，再看每页原图。对动态页对照 0、150、300、600ms 和最终状态，慢动作跨过这些采样点时补抓动作完成帧。交互另走一遍键盘、触摸或鼠标路径。静态页的动效项填“不适用”，注明媒介。

| 维度 | 检查动作与通过线（满分 5） |
|---|---|
| 主角 | 遮住文字，指出最先看到的轮廓和位置，≥4 |
| 页间差异 | 缩略图中相邻构图、动作、骨架可辨，≥4；单页用同题另一稿比对 |
| 尺度反差 | 以宽或高一致的线性量比较，最大与最小元素约六倍以上，留白有起伏，≥3 |
| 破框与重叠 | 每页有遮挡，系列有两到三处裁切或出血，≥3 |
| 材质与光 | 指出世界设定对应的边缘、纹理与投影，≥4 |
| 动效 | 顺序表达因果、过冲受控，降低动态后仍传达结果，≥3 |
| 原创性 | 核对标题、骨架、坐标、隐喻；记录复制项数，须为 0 |
| 可读性 | 去掉隐喻后仍能读清动作、单位、结论与条件，≥4 |

**每轮记录**：版本、画布、字体、页名、分数向量、看到的证据、最差三点、修订动作和复核结果。首轮低于阈值的页全部重做。次轮回看同一帧与同一画布；尚有低分继续迭代。包围盒相似度仅负责提示人工并排检查，不能自动判断原创性。

**版本对比**：用同一组 brief、相同内容、画布和资源分别生成两版；随机打乱左右，评分者只看成品和原题。先写判断与原因，再揭盲。固定样张重渲染仅验证实现，无法替代新任务的生成盲评。

从 brief 抄出需要核对的三个事实或动作。拿着截图，在不读世界设定的情况下逐一定位。若是音频、锁定状态或日程切换，实际操作一次，同时保存变更后的状态。缩略图的主次、可读性与任务完成情况分别记录；同一稿可能在不同项上胜负相反。
