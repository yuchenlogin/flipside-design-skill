# 三个世界，六个颜色角色

先独立写 world.md，再并读三列。下列三套都是实例，任何一套都没有默认优先级。

| 决定 | 序列的排印校样（实例） | 洞穴回声测距（实例） | 果园嫁接记录（实例） |
|---|---|---|---|
| 内容如何落地 | 当前词与上下文的权重由连线粗细编码 | 回波往返时长决定同心波前间距 | 接口与新芽的相对位置说明愈合方向 |
| 纸 / 墨 | #EFE8DA / #16161A | #EBF0ED / #172428 | #F3EAD4 / #201D25 |
| 冷深场 / 热主调 | #1E2A5E / #C4612F | #173D40 / #FA9151 | #30273F / #BB492E |
| 淡色 / 信号 | #E9B8BF / #EFCB45 | #ACCFCC / #F8D35F | #D9B9C3 / #DBEE68 |
| 系统 / 叙事 / 编号声 | Noto Sans SC / Noto Serif SC / Barlow Condensed | Archivo Black / Spectral / Barlow Semi Condensed | Bricolage Grotesque / Crimson Text / Archivo Narrow |
| 光与材质 | 硬光擦过压印边缘，版与纸错开一线 | 岩面横截，声源附近亮阶集中 | 不规则树皮切口，接穗压住切面 |
| 时间 | 先排定顺序，再压印定稿 | 向外传播，遇壁折返，读数停在回程末端 | 枝条就位后缠带逐圈收紧 |
| 抛弃条件 | 无顺序、组合或权重关系时弃用 | 波前不能解释读数时弃用 | 分叉与愈合不能解释对象时弃用 |

后两套字体用于拉丁文本，中文另选有字形覆盖的对应角色；实际字体以目标媒介的本地可用字库为准。

## v3 样张里值得留下的判断

- [封面](../examples/academic-deck/slide-01.jpg)让代词和被指代词同时进入视野，连线粗细直接表达注意力大小。图是机制示意。
- [结果页](../examples/academic-deck/slide-06.jpg)把两个可比较的测量值放到同一巨大尺度，单位与训练代价退到第二层。
- [讨论页](../examples/academic-deck/slide-07.jpg)让三张便签共用一条承重线，位置表达并列关系。这一局部成立，整页仍可改进主次。
- [结尾页](../examples/academic-deck/slide-08.jpg)用反白大标题先给结论，最后落下的章完成判断。

原型库只保留这些取舍作为依据。历史源文件在 academic-deck 内，复现 v3 时可取用独立的旧组件样式 v3-components.css。
