# 技术配方

从页面计划中选与材质、光和运动物理相符的一项。每份 HTML 都能离线独立打开。打开「调节与移植」查看参数范围、性能预算和降级方法。复制到项目时保留同一文件里的 CSS、标记与脚本，并用世界设定中的名称和数值替换示范参数。

| 配方 | 可观察的效果 |
|---|---|
| [套色错位](misregistration.html) | 移动两层色版，观察交叠处如何印出第三种颜色。适合强调套印边缘和焦点状态。 |
| [网点揭示](halftone.html) | 悬停、聚焦或按下按钮，网点扩张并接成完整的色面。正文和交互标签放在遮罩之外。 |
| [墨边抖动](ink-edge.html) | 让一个局部轮廓在两次印痕之间轻轻变化，保留字面的稳定边界。 |
| [指针驱动的硬投影](pointer-shadow.html) | 在样本周围移动指针。光靠近哪一侧，硬投影就向相反一侧偏移。 |
| [纸纤维](fiber.html) | 让低对比颗粒在一小块纸面上缓慢漂移。主信息放在独立的前景层。 |
| [盖章](stamp.html) | 按下按钮留下印迹。轮廓先接触纸面，残缺的着墨边缘在动作结束后保留。 |
| [滚动编排](scroll.html) | 沿页面向下滚动：画框停驻，标记随阅读进度移动，跨入下一章时整幅底色翻转。 |
| [加载即一幕](loading.html) | 每完成一条图形数据，就在结果上留下一道印痕。进度来自已经绘制的行数，载入完成后原位展示成品。 |

在目标设备上启用正常动效，连续交互时按每帧约 18 ms（55 fps）检查；浏览器性能轨迹能区分重绘与脚本成本。达不到预算就启用文件内的低负载模式。系统减弱动态设置可以在运行中切换。
